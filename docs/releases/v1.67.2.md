## 新增：发版自动打标签

- 版本号（`src/data/site.json` 的 `version`）一变，GitHub Actions 自动打同名 tag 并建 Release —— 不再需要人工去 GitHub 手写标签。
- 标签只打在「构建 + 自检全绿」的那个提交上；同一版本号后续再提交，默认跳过（tag 代表该版本号第一次出厂），需要每个提交都留标记可用 strict 模式，退化为 `v1.2.3-abc1234`。
- 标签是注释标签，带打标签的时间与提交信息；两种模式都不会移动已存在的标签。

## 新增：版本说明

- 每次发版的说明写在 `docs/releases/v<版本号>.md`，随代码一起提交；Release 页面正文取自这份文件，末尾附本次提交对比链接。
- 缺这份文件时不再留空白页面：正文会附上自动整理的提交列表并标出"未写版本说明"，同时在该次 Actions 的 job summary 里提醒补写。

## 修复

- **CI 里 14 首曲绘判空**：曲绘存在性原先只看本地素材目录有没有源文件，而该目录不入库、CI 里不存在，于是干净环境重建产物时这 14 首（音乐魔方世代，含首页 THRERROR）被判成空曲绘并回写快照，导致 `build-check` 每次必红。现改为以图床映射表（`src/data/cdn.json`）为主要判据，并新增断言"有图床映射却无 cover"必须为 0。
- **注释标签缺作者身份**：Actions runner 没有全局 git 身份，首次真跑死在 `fatal: empty ident name`；改为就地指定 `github-actions[bot]` 身份。
