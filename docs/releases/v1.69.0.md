# v1.69.0

## 首页字标统一宽度

- 所有世代的首页字标改为**同一渲染宽度**（以 U'nit 那张为准），不再各代一大一小。
  实现：`.word-line` 新增 `--wl-w`（= 参考字号 × 7.8086），各世代新增 `--wl-ar`（宽高比数值），
  `#wordLogo` 宽度由 `--wl-w` 定量、高度按 `--wl-ar` 反推；`.word-l` 的上移量随之改成
  「图高 = 宽度 / 宽高比」，字身带中心仍压在文字中线上（这是原先 `--bh` 那套对齐的前提）。
- 窄屏沿用同一系数，随 `--wl-em` 一起收敛。

## 曲目页

- JP 服务器卡片图标换成 U'nit 字标（`SRV_CARDS` 的 `logo: 'unit'`，世代口径同步为 `U'nit`）。
- 国服曲目缺曲绘时统一用共享占位图 `idph-cn.webp`：图床映射写在 `src/data/cdn.json`，
  API 白名单放行该名字，`build-db` 在 `webpCover()` 拿不到图时回退到它。
  `covers.ts` 也补了「cover 名本身就是映射 key」的查表路径（共享占位图靠这条才解析得到）。

## 歌曲详情页

- Notes 没有抓到时也照常渲染这一格，总数印「暂无」并打 `is-none`，与 Holds 的空态同构，
  两块读数始终等高；参照条与分位只在真有数据时出现。

## 修复

- **首页 4×4 方阵在 U'nit 世代不显示曲绘**：`covers.ts` 在只有 cover、没有 songId 时
  用 `/^id(\d+)\./` 抠 id，占位 id（`idunit-013.webp`）抠不出纯数字 → id 为空 →
  直接回退站内 `/assets/images/jackets/…` → 404。改成抠 `id` 前缀后的整段，
  映射表命中后走 `/api/jacket`。
