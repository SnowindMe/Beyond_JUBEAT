## 新增

- **首页 Pop 调查浮标**：主人给的腾讯问卷嵌入代码是一块写死 `#699ef5` 的蓝色竖条，16 套世代主题切过去它都是一块蓝。改成站内玻璃板（`--glass2` / `--edge`），左侧只留一条 3px `--acc` 强调线，主题切换自动跟随；补 hover / focus-visible / reduced-motion 三态，并给一个关闭键（按天记，当天点掉、次日重来）。
- **浮标只在首页出现**：`Base.astro` 新增 `showVote` 开关，全站默认关。浮标要的是「首页来的人顺手投一票」，挂到每一页反而成噪音。
- **窄屏换形态**：竖条 38×142 在 390 宽下正好压住「相关站点」标题与第一行友链，改成贴左下角的短药丸（44px 高）；桌面保持竖排，用 `text-orientation: upright` 让 "Pop" 逐字直立而非整体躺倒。

## 修复

- **固定件被祖先 transform 拽回文档流**：浮标最初写在 `index.astro` 的 `<Fragment slot="float">` 里，而 Astro 的 slot 是原地展开，元素仍在 `<main>` 内、被 `.wrap` 的 `transform`（哪怕只是 identity matrix）变成相对祖先定位，`bottom` 算的是整页高度，浮标跑到首屏视野外（实测 y=1006 而视口只有 805）。改成由外壳按 `showVote` 直接渲染在 body 层，与 BackTop 同层。
