# v1.68.1 —— 修 U'nit 主题下首屏方阵与详情页曲标

## 修复

- **首屏曲绘方阵没跟着主题切**：`Hero.astro` 的「主题 key → 世代名」映射表漏了 `unit`，
  切到 U'nit 后仍显示上一个世代的曲绘。补上 `unit → U'nit`。
- **曲目详情页的世代曲标**：`GEN_LOGO` 同样漏了 U'nit，详情页曲标退化成默认字标。
- **方阵补位**：U'nit 目前只有 14 首（其他世代都 ≥16），4×4 方阵会留两个空格。
  改成不足 16 时按序循环补位，宁可重复两格也不留洞。

## 说明

这两处都是「加世代/加主题要同步改的清单」漏项，已在代码注释里点明：加主题时
`Hero.astro` 的 THEME2GEN 与 `[songId].astro` 的 GEN_LOGO 必须一起加。
