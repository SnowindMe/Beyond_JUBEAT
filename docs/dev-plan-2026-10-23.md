## 四、硬约定（全队遵守）

1. 只有 t8 改 src/data/site.json 版本号，避免 8 个任务并发改同一个数字。
2. 每个实现任务自己同步自己那段文档；README 只在 t8 统一收口。
3. 新增 prerender=false 路由必须同步 wrangler.jsonc 的 assets.run_worker_first（漏了会被资源层 404.html 截住）。
4. 本地 workerd 起不来，接口/页面真机行为一律 push 后打线上验收；本地只保证 npm run build + npm run check 通过。
5. 所有成员不 git push、不 wrangler deploy；push 由主人在 review 时点头后执行。
6. 高权限接口必须服务端复核 role；密码/会话红线见项目 rules，不得回退。
7. 改完不刷版本号，不删别的任务的活。
